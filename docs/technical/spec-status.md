## What the statuses mean

- **active** — open tasks, and CLAUDE.md points at it as current work.
- **blocked** — every open task declares its own blocker (missing tool, missing asset).
- **dormant** — open tasks, but nothing in CLAUDE.md claims it is being worked on.
- **done** — every task ticked.
- **closed** — a `**STATUS: CLOSED/SUPERSEDED**` banner; kept for the record.

## What the flags mean

- **MISSING** — an OPEN task names a file that is not in the tree. Either the design
  was replaced underneath it, or the file is the task's own unbuilt deliverable.
  Only raised while work is open: a finished spec naming a retired asset is history.
- **LIKELY-SHIPPED** — an open task names only files that already exist. Strong hint
  the work landed in another session and the box was never ticked. This is exactly
  how `specs/collegium-client/` sat at 0 of 7 while its code ran fine every day.
- **CLAIM** — CLAUDE.md calls the spec complete while unblocked tasks are open.
  Either the summary overstates, or the boxes were never ticked. Both have happened.
- **STALE** — open tasks, untouched for over 45 days.

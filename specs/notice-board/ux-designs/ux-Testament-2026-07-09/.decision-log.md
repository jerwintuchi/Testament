- **2026-07-09 — PIPELINE SETTLED: STAY ON STDLIB PNG (no Pillow).** The env has no
  `pip`/`ensurepip`; Pillow would need `sudo apt install python3-pil` (password-gated,
  not performable here) and adds a system dependency. Stdlib needs nothing and already
  proves the asset classes in `gen_board.py` (per-pixel RGBA, distance-gradient rim,
  value noise, organic torn/deckled alpha). Torch glow = radial alpha falloff; cobweb =
  thin alpha strands; foxing = blotch noise — all in the existing idiom; soft-glow via a
  falloff function (or a ~10-line box blur) rather than PIL blur. Pillow remains a
  sanctioned fallback if generator complexity ever demands it (user runs the one apt cmd).
  Resolves art-canon high finding #2.

- **2026-07-09 — FIX CLUSTER APPLIED (from validation):**
  - Headline ink = `#2A2115` (NOT wax `#8F2F2A`); wax demoted to non-text accent only.
  - Numeric legibility floor: a LIVE notice renders at ≥ `parchment.base` (never shadow)
    with a torch/local-glow contribution; headline + body ≥ 4.5:1 vs the composited
    (post-gloom) local backing, verified on a worst-case seed.
  - Threat pips: every pip a 1px `#12100C` outline; empty pip = outlined-hollow diamond.
  - Live legibility independent of scatter: each live notice carries its own local
    backlight (not reliant on the two wall torches reaching it).
  - Layout keep-out: each live notice's headline+target+seal+pip band is a deterministic
    keep-out rect no other notice/cobweb/votive/foxing may overlap; decay props bound to
    corners proven empty of live anchors; min live hit-target ≥ 44×44 un-occluded.
  - Pixel integrity: seeded tilt via pre-baked rotated deckle variants (or a pixel-art
    rotation shader); hover/reader scale in INTEGER steps only.
  - VFX per canon: torch glow + cobweb = GRAYSCALE additive source, `modulate`-tinted to
    the flame ramp (not colored screen-blend); no off-ramp pixel — blended/lit output
    quantized back to the locked palette before export.
  - Reduced-motion: static glow pinned to PEAK brightness (never the dim trough); only the
    pulse is decorative; explicit in-game toggle (Godot has no auto prefers-reduced-motion).
  - States added: empty-board, error surface (top-centre toast/status line), pressed/
    in-flight seal, faint-seal ring at full strength, Origin = sigil-shape (color redundant).
  - Focus/keyboard floor: live notices focusable (Tab = reading order), gold focus ring
    (≥3:1), Enter/Space activates; seal focus-reachable.
  - Flows added: deselect/lift beat; non-leader companion flow; raced-error surface named;
    two-stage DEPLOY notes DEPLOYING is staging (field on a 2nd Deploy).
  - Copy: dropped off-register "AUTHORIZED"; seal captions annotated with role/state.
  - Refs: key-screen mock linked + promoted to mockups/; palette-candidates breadcrumb;
    sources path-base noted; typography minimum glyph size floor.
